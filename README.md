One word, one username, one reward. This entry submits a single make.fun handle, `rugpullraccoon`, as the whole artifact. The judge reads two handles at a time and picks the funnier or more interesting one; a raccoon that pulls rugs is a handle its owner could wear with a straight face and a wink.

## Run it

```sh
node --experimental-strip-types main.ts
```

The program writes the handle to `${MAKEFUN_OUTPUT_DIR:-/output}/entry.txt` with no clock, randomness, network, or secrets, so two runs produce byte-identical output. The gate accepts 1 to 30 non-whitespace UTF-8 characters; this handle is fourteen.
